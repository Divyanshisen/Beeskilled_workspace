# Titanic Survival Prediction – Data Cleaning Project

## Overview

This project was completed as part of Week 1 of the Beeskilled Data Science Internship. The objective was to explore, clean, preprocess, and prepare the Titanic dataset for machine learning applications.

## Objectives

- Load and explore the Titanic dataset
- Analyze dataset structure and statistics
- Handle missing values using appropriate imputation techniques
- Encode categorical features for machine learning
- Visualize passenger age distribution
- Export the cleaned dataset as a new CSV file

## Dataset

The project uses the Titanic Dataset, which contains information about passengers such as age, gender, ticket class, fare, embarkation point, and survival status.

## Tasks Performed

### 1. Dataset Exploration
- Loaded dataset using Pandas
- Examined dataset structure using `.info()`
- Generated statistical summaries using `.describe()`

### 2. Data Cleaning
- Identified missing values
- Filled missing values using median and mode imputation
- Verified data quality after preprocessing

### 3. Feature Encoding
- Applied Label Encoding to categorical features
- Applied One-Hot Encoding where appropriate

### 4. Data Visualization
- Created age distribution visualization using Matplotlib

### 5. Dataset Export
- Saved the cleaned dataset as `Titanic_Cleaned.csv`
